# Controls

Every key the mod binds, by group, as it comes. Keys are keyboard only. F1 shows the subset that does something where you are; that is usually what you want.

The mod menu's All keys lists the same, by group. The mod's own keys cannot be changed yet; the encounter keys the game itself binds follow the game's Key Bindings options.

## Global

| Key | Function |
| --- | --- |
| F1 | Keys here: the keys that do something on this screen, each runnable with Enter |
| Ctrl+Shift+M | Mod menu |
| Ctrl+Shift+A | Toggle keyboard navigation |

## Navigation

| Key | Function |
| --- | --- |
| Arrows | Move focus; Left/Right change a chooser or slider |
| Tab / Shift+Tab | Next / previous control group |
| Enter | Activate |
| Backspace | Secondary action: details, where a control has them |
| Escape | Back, cancel, close |
| Home / End | First / last item of the list |
| Alt+Up / Alt+Down | Previous / next section |
| Letters | Type-ahead search in the focused group |

## Buffers

| Key | Function |
| --- | --- |
| Ctrl+Right / Ctrl+Left | Next / previous buffer |
| Ctrl+Up / Ctrl+Down | Next / previous line |

## The Encounter: The Game's Keys

These are the game's own actions, so they follow its Key Bindings options. The defaults:

| Key | Function |
| --- | --- |
| S | Budge the focused die up |
| A | Budge the focused die down |
| F | Freeze or unfreeze the focused die or shop choice |
| R | Reroll with Chrono |
| E | Proceed: launch, or leave the shop |
| Q | Cancel: undo a budge |

On the reroll, budge, and Mini-Dice buttons, S, A, and F act on the die or shop choice you were last on. A budge or freeze says the die after; one the game refuses says so.

## The Board

| Key | Function |
| --- | --- |
| Arrows | Move one cell |
| Home / End | First / last column of the row |
| Page Up / Page Down | Top / bottom row of the column |
| Enter | While choosing a target, choose it; in the shop, buy |
| Backspace | Details: the unit's or perk's tooltip and keywords |
| Escape | The game menu; while choosing a target, cancel |
